# Security

This library parses files that may come from untrusted sources. If you find a way to make it read
outside its folder, reach the network, run code, exhaust memory, or accept a malicious XML or ZIP, or
if it reads a real document wrongly in a way that hides a problem, please do not open a public issue.
Write to research@eqlx.ai or use GitHub's "Report a vulnerability" button on the Security tab. Do not
send real invoices or ledgers; describe the structure instead. We aim to reply within five working days.
